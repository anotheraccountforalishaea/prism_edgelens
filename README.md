# PRISM

AI model recommendation system for edge devices.

## Features
- Parses user AI requirements
- Suggests AI models
- Scores models based on device constraints
- Frontend + Backend integration

## Run Backend
npm install
npx ts-node src/server.ts

## Run Frontend
cd frontend
npm install
npm run dev

## Frontend URL
http://localhost:5173

## Backend URL
http://localhost:8000
